# CAD & 3D Printing Designs

Design files from a hands-on CAD/3D-printing course — not software, but included as
a portfolio of physical design work: 3D modeling, print-ready mesh preparation, and
slicing.

| Project | Files |
|---|---|
| [`assignment-4-print/`](assignment-4-print/) | Print-ready model + design writeup. |
| [`assignment-6-print/`](assignment-6-print/) | Print-ready model. |
| [`mini-project/`](mini-project/) | A two-part assembly, plus the design writeup. |
| [`final-project/`](final-project/) | The course's capstone design. |
| [`keychain-prints/`](keychain-prints/) | Two personal prints — a keychain and a twisted infinity-loop design. |

Each `.stl` is the raw mesh; each `.3mf` is the print-ready project file (mesh + slicer settings) for PrusaSlicer/Bambu Studio-style tools.

**Not included:** a higher-poly Blender sculpt from this course's final assignment (source `.blend` + exported `.stl`) was left out — the files run 45-120MB each, too large for a source-controlled repo like this one.

## 🎓 Project Context

Built as part of **MECH 150: Introduction to Engineering Design and Innovation** at
the University of Victoria.
